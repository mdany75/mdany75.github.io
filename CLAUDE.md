# mdany75.github.io

Page d'accueil statique (un seul `index.html`, CSS et SVG en ligne, aucune dépendance).
- Design « cartes colorées » ; thème clair/sombre automatique.
- Ajouter une application : copier un bloc `<a class="card ...">` dans le `<nav>`.
- Textes en français. Pas de build : tester avec `python3 -m http.server`.
